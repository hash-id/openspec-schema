# OWASP Top 10 for LLM Applications 2025

For any feature that calls a language model, builds prompts, uses embeddings, or retrieves context. Walk each line once. If the model is given tools, also read `agentic-top10-2026.md`.

- LLM01 Prompt Injection: can untrusted text change what the model does?
- LLM02 Sensitive Information Disclosure: can the model leak personal data, financial or health data, credentials, confidential business data, or proprietary model details?
- LLM03 Supply Chain: are third-party pre-trained models, datasets, plugins, and libraries from trusted, pinned sources?
- LLM04 Data and Model Poisoning: can training, fine-tuning, or retrieval data be tampered with?
- LLM05 Improper Output Handling: is model output validated before it reaches a shell, query, browser, or another system?
- LLM06 Excessive Agency: does the model have more tools, permissions, or autonomy than the task needs, and is there human approval for risky actions?
- LLM07 System Prompt Leakage: are secrets or access rules placed in the prompt?
- LLM08 Vector and Embedding Weaknesses: is retrieval access-controlled, and can embeddings be poisoned or leak data?
- LLM09 Misinformation: can wrong output cause harm without a check?
- LLM10 Unbounded Consumption: are there limits on tokens, calls, and cost per user?

Source: https://genai.owasp.org/llm-top-10/ (current edition shown there: 2025).
