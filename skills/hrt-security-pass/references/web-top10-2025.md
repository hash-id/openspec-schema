# OWASP Top 10:2025 (web applications)

For server-rendered pages, templates, browser frontends, and the backends behind them. Walk each line once: add a threat only if the category applies and no listed threat covers it.

- A01 Broken Access Control: does every object, function, and URL check who is asking, on the server? Includes exposure of sensitive information, SSRF, and CSRF.
- A02 Security Misconfiguration: unsafe defaults, debug on, open permissions, missing hardening, XML external entity (XXE) handling?
- A03 Software Supply Chain Failures: a new dependency, build step, install script, or distribution channel; is the source trusted and pinned? Not limited to known-vulnerable components.
- A04 Cryptographic Failures: data unprotected or weakly protected at rest or in transit; broken or risky algorithms, weak randomness, leaked keys?
- A05 Injection: untrusted input reaching a query, command, template, or interpreter? Includes SQL injection and cross-site scripting.
- A06 Insecure Design: can a legitimate flow be abused, or is a control missing by design?
- A07 Authentication Failures: weak login, session, credential recovery, or MFA; hard-coded credentials, session fixation, improper certificate validation?
- A08 Software or Data Integrity Failures: unsigned updates or artifacts, unsafe deserialization, code or data included from an untrusted source?
- A09 Security Logging and Alerting Failures: are security events recorded and alertable, with secrets kept out of logs?
- A10 Mishandling of Exceptional Conditions: do errors and logic faults fail closed (not open), release resources, and not leak detail in messages?

Source: https://top10.owasp.org/2025 (the page does not state a final or release-candidate status).
